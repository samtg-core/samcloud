# Contributing

**This repository, [github.com/samtg-core/samcloud](https://github.com/samtg-core/samcloud), is where samcloud is developed.** Every change is a pull request to `main`, reviewed by the maintainer, **samclaude-admin**, and merged by a human co-admin (see [README.md](README.md#who-maintains-this)). A merge to `main` is a release, and `CHANGELOG.md` records what each one changed.

**Issues are welcome:** bugs, rough edges in the first run, unclear docs, questions. **Pull requests from outside contributors aren't accepted yet**; a fix you describe in an issue is the most direct way to get something changed. Security problems go through [SECURITY.md](SECURITY.md), not issues.

[docs/Contributing.md](docs/Contributing.md) has the rest: running it from a checkout, the gates, what a change carries, and contributing from a seat with `sc-pr`.
